# ComfyUI 工作流配置

`comfyui` 适配器通过 ComfyUI 的 HTTP API 提交工作流：

1. `POST /prompt` 入队工作流；
2. 轮询 `GET /history/{prompt_id}` 等待执行完成；
3. 通过 `GET /view` 下载输出图片，图生图会先调用 `POST /upload/image` 上传参考图。

适配器只负责提交与取回结果，模型、采样器、LoRA 等全部由工作流决定。

## 1. 准备 API 格式工作流

在 ComfyUI 界面中打开能正常出图的工作流，使用「导出（API）」（旧版为 `Save (API Format)`）保存 JSON。

> 必须是 **API 格式**，而不是普通的界面格式。界面格式包含 `nodes`、`links`、`subgraphs`，服务端无法直接执行。

导出后，在插件配置的「工作流文件」中直接上传该 JSON 即可，无需手动填写路径。文件会保存到插件数据目录：

```text
data/plugin_data/astrbot_plugin_image_generation/files/...
```

## 2. 添加供应商

在插件配置的「图像模型供应商」中添加 `ComfyUI 工作流`：

| 配置项 | 示例 | 说明 |
| :--- | :--- | :--- |
| 供应商名称 | `ComfyUI` | 模型格式为 `ComfyUI/模型名称`。 |
| 接口地址 | `http://127.0.0.1:8188` | ComfyUI 服务地址。 |
| 工作流文件 | `qwen_image_2_1_t2i_api.json` | 上传 ComfyUI 导出的 API 格式 JSON；重新上传后下次生图自动生效。 |
| 可用模型列表 | `qwen_image_2_1_t2i` | 可填任意显示文本，仅用于 `/生图模型`、页面选择和日志展示，不会发送给 ComfyUI；实际模型由工作流决定。 |
| 模型能力 | `文生图` | 需要图生图、宽高比或分辨率时再勾选并完成下方映射。 |
| 超时时间 | `180` | 总生成等待时间；超时视为任务失败并尝试取消任务。填 0 使用“运行控制”中的超时。 |
| 轮询间隔 | `2` | 查询 `/history` 的间隔，通常建议 1～2 秒。 |
| 超时后取消任务 | 开启 | 优先调用 `/api/jobs/{id}/cancel`；接口不可用时仅尝试移出排队。 |

> 工作流文件字段只使用上传列表中的第一个 `.json` 文件。

## 3. 提示词写入

默认会从采样器的 `positive` 输入向上查找文本节点，并把用户提示词写入沿途的文本字面量：

- 标准工作流：写入 `CLIPTextEncode.text`；
- 带提示词增强开关的工作流：同时写入开关的 `on_false` 和增强节点的 `prompt`，无论开关是否开启都使用用户提示词；
- 找不到文本节点时，请显式配置「提示词节点 ID」，多个候选节点用逗号分隔。

「提示词输入名」留空时自动选择 `prompt` 或 `text`。

Qwen Image 2.1 文生图模板的提示词链路会被自动识别，无需额外配置。

## 4. 图生图

1. 工作流中需要存在 `LoadImage` 节点；
2. 勾选「模型能力」中的「图生图」；
3. 可选配置「图片节点 ID」，多个节点按参考图顺序用逗号分隔；留空自动查找 `LoadImage`。

适配器会把每张参考图上传到 ComfyUI 的 `input` 目录，然后把返回的文件名写入对应节点的 `image` 输入。

> 参考图多于图片节点时，多余图片会被忽略；图片少于节点时，未覆盖的节点保留工作流中的原值。

## 5. 宽高比与分辨率

勾选「宽高比」或「分辨率」后，适配器会尝试把参数映射到工作流：

- **宽高比节点**：留空自动查找带 `aspect_ratio` 文本输入的节点。枚举候选项会从 `/object_info/{节点类型}` 获取，例如 `16:9` 会匹配 `16:9 (Widescreen)`；同时把分辨率换算为 `megapixels`（1K≈1、1.5K≈2.25、2K≈4、4K≈16）。
- **尺寸节点**：留空自动查找同时带 `width`、`height` 数值输入的节点，例如 `EmptyLatentImage`。优先使用「尺寸映射」，未命中时使用内置 1K/2K 比例表，仍无结果则按比例计算；宽高会对齐到 8 的倍数。
- 两者都可以通过显式节点 ID 覆盖自动检测。

「尺寸映射」默认已预置 1K 下的 `1:1`、`4:3`、`3:4`、`16:9`、`9:16`；2K/4K 会更吃显存，可在需要时补充；其他比例或分辨率会自动计算。示例：

```json
{"1K:16:9": "1024x576", "2K:1:1": "2048x2048"}
```

匹配顺序：`分辨率:宽高比` → `分辨率` → `宽高比` → `default`。

Qwen Image 2.1 模板使用 `ResolutionSelector`，会自动应用宽高比与分辨率。

## 6. 常见问题

| 现象 | 处理 |
| :--- | :--- |
| `工作流参数无效: ... Value not in list` | 工作流节点的枚举值与插件传入值不匹配，请显式配置节点 ID，或改用适配器支持的宽高比。 |
| `未上传 ComfyUI 工作流文件` | 在「工作流文件」中上传 ComfyUI 导出的 API 格式 JSON。 |
| `Value not in list: clip_name` | 工作流引用了目标 ComfyUI 未安装的模型。即使该节点因开关关闭不会执行，ComfyUI 仍会校验模型文件；请补齐模型或把节点改为已安装的模型。 |
| `未找到可写入提示词的工作流节点` | 配置「提示词节点 ID」与「提示词输入名」。 |
| `工作流未包含 LoadImage 节点` | 图生图工作流缺少 `LoadImage`，或需要配置「图片节点 ID」。 |
| `ComfyUI 未返回图片结果` | 工作流执行成功但没有图片输出；确认存在 `SaveImage`/`SaveImageAdvanced` 等输出节点。 |
| 连接失败 | 确认 ComfyUI 已启动且「接口地址」可访问；首次加载模型可能需要较长时间，可调大「超时时间」。 |
| 超时 | 达到「超时时间」后任务视为失败；默认会尝试取消该任务。取消失败或关闭「超时后取消任务」时，任务会继续在 ComfyUI 中运行。 |
| 显存不足 / 生成很慢 | 8GB 显存建议使用 1K；2K 约为 1K 的 4 倍像素，4K 约为 16 倍。可先用 1K 生成，再接放大节点。 |
